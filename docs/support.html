Support

Something off? Tell us from Blender.

The fastest way to a fix is a bug report from inside Blender: FlexSpace adds your versions, system and recent errors for you, and you review it on GitHub before you submit it.

Report a bug Troubleshooting
Report a bug

From the canvas header.

Open Help > Report a Bug... in the canvas header, or Report a Bug in the add-on preferences. FlexSpace adds the Blender and FlexSpace versions, your system and GPU, the canvas, the modules and its last errors of this session. Nothing is sent by FlexSpace itself, and your home folder in any file path is replaced by ~.

Tip: a few steps to reproduce it, and a small .blend if you can share one, make a fix much quicker.

What happens

  1. Write a title, what happened, the steps to make it happen again, and what you expected.
  2. Click Open on GitHub: a new issue opens in your browser, filled in.
  3. Review it and submit it there.
  4. No GitHub account? Click Copy Report and paste it in a comment on the product page or in an email.
