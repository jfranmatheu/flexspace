BLENDER 5.3+ ADD-ON · V1.4.1

Build the Blender panel you always wanted.

FlexSpace turns any area into a canvas for your own controls. Lay out buttons, sliders, toggles, colour pickers and a sculpt-ready Ring Menu, bind them to any property, operator or script, and use them while you work. And when it's time to animate, the Armature Picker puts every bone of your rig one click away.

BINDING

Bind anything with a right-click.

Right-click any property or button in Blender and choose Add to FlexSpace Canvas, then a page: the right widget lands there, already bound and labelled. The canvas you used last comes first. From the canvas itself, Shift A › From Property does the same. Widgets show Blender's animation colours, I keys them, and Auto Keying just works.

GEOMETRY NODES

Six Geometry Nodes systems. One canvas.

The City Builder demo is a procedural island city: the island, the sea, the streets with their traffic, the buildings, the forest and the street lights, each its own Geometry Nodes system. One canvas page shapes the island and its coastline, the streets, the buildings, the forest and the night lights, and the sea follows the coast. Drag Grow and the city rises from its empty plots; drag Nightfall and the sun sets, the windows and the street lamps light up and the night falls.

ARMATURE PICKER

Pose without hunting for bones.

A picker is a canvas of buttons that select the bones of your rig. It's saved with the armature, so it travels when you link or append the rig, and your Pose Mode keys keep working over it. Using Rigify? Add a full Humanoid Body picker (body, hands, feet and face) in one step.

FAQ

Questions, answered.

Is it a Blender fork or separate software?

Neither. FlexSpace is a regular Blender extension that runs inside the Blender you already use (5.3 or newer). Install the zip from Edit › Preferences › Get Extensions › Install from Disk... and that's it. No custom Blender build, no external app, nothing else to install. It also works in a studio's in-house Blender build, as long as it's based on 5.3+ and supports extensions.

Which Blender versions does it support?

Blender 5.3 or newer. FlexSpace is a Blender extension: install the zip from Edit › Preferences › Get Extensions › Install from Disk.... Getting started →

Is the Armature Picker included?

Yes. FlexSpace comes with two canvases: Flex Space for control panels and Armature Picker for rigs. The Armature Picker →

Does the picker work with my rig?

Any armature works: import selected bones and place their buttons. Rigify rigs get a full Humanoid Body picker in one step. Buttons follow renamed bones, and Repair Bone Bindings fixes the rest. Picker with Rigify →

Can my team share panels?

Yes. Save a canvas as a global preset, export it as a .flexspace file, or set a shared presets folder on a network drive. Global presets →

Will my shortcuts still work?

Yes. The canvas uses its own keys first; any other key goes to Blender's keymap, Industry Compatible and custom bindings included. Shortcuts →

Can a button run my own Python?

Yes, with a Custom Script button. Buttons from an untrusted file ask before running. Widgets →

What if something breaks?

Open Help › Report a Bug... in the canvas header: it opens a GitHub issue with your versions and recent errors filled in. Troubleshooting →
