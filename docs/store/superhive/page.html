Blender 5.3+ add-on · v1.4.0

Build the Blender panel you always wanted.

FlexSpace turns any area into a canvas for your own controls. Lay out buttons, sliders, toggles, colour pickers and a sculpt-ready Ring Menu, bind them to any property, operator or script, and use them while you work. And when it's time to animate, the Armature Picker puts every bone of your rig one click away.

The canvas

Two modes. One canvas.

Build your panel in Edit Mode, use it in Live Mode. On a picker, Live Mode is Blender's own Pose Mode.

Edit Mode

Lay it out.

Add widgets with Shift A, then drag, resize, rotate, snap, group and frame them.

Tabswitches between them
Live Mode

Use it.

Click buttons, drag sliders, flip toggles. Every change is one undo step.

What you get

Your tools, where your hands are.

Control panels

Every control, one click away.

Lights, render settings, playback, modifiers, materials: put the controls you reach for on one canvas, in the order that makes sense to you. Buttons run operators or your own Python scripts; sliders, number fields, toggles and enums drive any property.

  • Operator and Custom Script buttons
  • Sliders, Number Fields, Toggles, Enums, Lists
  • Labels that read values out, images and frames

In Blender

Binding

Bind anything with a right-click.

Press Shift A › From Property, right-click any property in Blender, and the right widget appears, already bound and labelled. Widgets show Blender's animation colours, I keys them, and Auto Keying just works.

  • Data paths, eyedropper or From Property
  • Follow the active object or pin one
  • Visible When and Disabled When conditions

The eyedropper asks for the right kind of property, then fills in the data path for you.

In Blender

Layers

One canvas for every mode.

Give each layer its moment: always, in one Blender mode, for one object, or for one object in one mode. Switch to Sculpt Mode and your sculpt layer is there; select the tower and its Geometry Nodes controls show up.

  • Show When: Always, Mode, Object, Object in Mode
  • Switch Layers Automatically
  • A clear notice, and one click to enter the right mode

In Blender

Ring Menu

A sculpt wheel that stays put.

Brushes in the outer ring, toggles and operators in the inner ring, the active brush named in the core. It lives on the canvas: no pie to summon, no menu to close. Fill it with every Essentials brush in one click and page through the rest.

  • Brushes, toggles and operators
  • Pages for more brushes
  • Disabled When per item

Also on the canvas: Color Picker, Color Palette and Brush Picker.

  • Color Picker
  • Color Palette
  • Brush Picker

The Sculpt Wheel demo has every Essentials sculpt brush, ready to try.

In Blender

Armature Picker

Pose without hunting for bones.

A picker is a canvas of buttons that select the bones of your rig. It's saved with the armature, so it travels when you link or append the rig, and your Pose Mode keys keep working over it. Using Rigify? Add a full Humanoid Body picker (body, hands and feet) in one step.

  • Bone buttons, custom shapes and mirroring
  • IK/FK switches, knobs and 2D pads
  • Bone collection toggles

Presets

Build it once. Use it everywhere.

Save a canvas as a global preset and add it to any project. Linked canvases know when the preset changed, keep your local edits until you choose, and can restore any of the last 5 versions. Export a .flexspace file, or point your team at a shared presets folder.

  • Up to date, Modified and update badges
  • .flexspace export and import
  • Shared team folder

Rigify? One step.

In the picker's Edit Mode, press Shift A and choose Bone Picker › Humanoid Body (Rigify).

FAQ

Questions, answered.

Which Blender versions does it support?
Blender 5.3 or newer. FlexSpace is a Blender extension: install the zip from Edit › Preferences › Get Extensions › Install from Disk.... Getting started →
Is the Armature Picker included?
Yes. FlexSpace comes with two canvases: Flex Space for control panels and Armature Picker for rigs. The Armature Picker →
Does the picker work with my rig?
Any armature works: import selected bones and place their buttons. Rigify rigs get a full Humanoid Body picker in one step. Buttons follow renamed bones, and Repair Bone Bindings fixes the rest. Picker with Rigify →
Can my team share panels?
Yes. Save a canvas as a global preset, export it as a .flexspace file, or set a shared presets folder on a network drive. Global presets →
Will my shortcuts still work?
Yes. The canvas uses its own keys first; any other key goes to Blender's keymap, Industry Compatible and custom bindings included. Shortcuts →
Can a button run my own Python?
Yes, with a Custom Script button. Buttons from an untrusted file ask before running. Widgets →
What if something breaks?
Open Help › Report a Bug... in the canvas header: it opens a GitHub issue with your versions and recent errors filled in. Troubleshooting →
