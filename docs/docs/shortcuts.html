Shortcuts

Keys work with the mouse over the canvas. A key the canvas doesn't use goes on to Blender's own keymap (yours, if you changed it).

Everywhere on a canvas#

Key Action
TabSwitch between Edit Mode and Live Mode (Pose Mode on a picker). It also works on a canvas dimmed by its page's mode.
Middle mouse dragPan
WheelZoom
HomeFrame every widget
NSidebar
TToolbar
Ctrl+ZUndo
Ctrl+Shift+ZRedo
EscLeave the open group (Edit Mode). Otherwise Blender's (stop playback...).
Space, Ctrl+Space, Ctrl+S, F keys...Blender's, as usual

Edit Mode#

Key Action
Shift+AAdd a widget: type to search, Enter adds
ClickSelect
Shift+ClickAdd to the selection
Drag on empty spaceBox select
ASelect all
G / R / SMove / rotate / scale
Alt+RClear rotation
Arrow keysNudge 10 units (Shift: 1 unit)
Shift+DDuplicate
Ctrl+C / Ctrl+VCopy / paste (into this or another canvas of the same kind)
X or DeleteDelete
Ctrl+G / Alt+GGroup / ungroup
Double-click a groupEnter it
Ctrl+ClickPick a widget inside a group
Ctrl+J / Alt+PFrame the selection / remove from frame
MMove the selection to another page (with two or more pages)
Right-clickContext menu
AltShow the pivot handle to drag it

While moving, resizing or rotating#

Key Action
X / YLock an axis (move, scale)
ShiftLock the axis of the drag (move), keep or free the ratio (resize), 15 degree steps (rotate), finer (scale)
CtrlSnap (or drag free when smart snapping is on). 5 degree steps when rotating.
AltFrom the centre (resize), each widget on its own (rotate, scale), don't drop into a Flex Box (move)
Type a numberExact value
Enter or ClickConfirm
Esc or Right-clickCancel

Live Mode#

Key Action
Click a widgetUse it (run a button, flip a toggle)
Drag a sliderChange its value
Shift while dragging a Lineal slider or a Number Field10 times finer
Ctrl while dragging a Lineal slider or a Number FieldSnap to the property's step (a Number Field with a Custom Step: to that)
Ctrl + Click or Double-click a Lineal sliderType the value (Enter applies it)
Click a Number FieldType the value (Enter applies it); on an end arrow (Show Arrows), one step

Radial slider: Shift is finer, Ctrl snaps.

With the mouse over a widget bound to a property (a slider, toggle, enum, number field, color swatch or color picker), as over a Blender button:

Key Action
IInsert a keyframe on that property
Alt+IDelete its keyframe on the current frame
Shift+Alt+IClear all its keyframes
BackspaceReset it to its default value

Note Anywhere else (over a bone button or empty space) these keys stay Blender's Pose Mode keys: I keys the selected bones.

Picker, Pose Mode#

Key Action
Click a buttonSelect its bone
Shift+Click a buttonAdd its bone to the selection
Drag on empty spaceBox select bones
Click empty spaceDeselect all
Right-clickInsert Keyframe pie (with an active bone)

Your Pose Mode keys work as in the 3D Viewport: G R S, I (insert keyframe), A / Alt+A, H / Alt+H, Ctrl+C / Ctrl+V (copy / paste pose) and the rest.

Minimap#

Key Action
ClickCentre the view
DragPan
Double-clickFrame all
WheelZoom
